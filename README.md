## 🏆 Selected work

### 🍽️ [NutriCore — Hybrid Diet Recommender](https://github.com/Tanmay0448/nutricore-hybrid-diet-recommender)

*Python · Streamlit · pandas · scikit-learn · scikit-surprise · SQLAlchemy · SQLite*

NutriCore is a personalized diet-recommendation and meal-planning application that combines taste preferences with nutrition-aware ranking.

- Processed **522,517 Food.com recipes** and **1.4M reviews** into **302,965** usable recipe records and **788,843** aligned reviews.
- Derived Vegetarian, Eggitarian, and Non-Vegetarian filters directly from ingredient data.
- Calculated BMR using the Mifflin-St Jeor equation and created **seven** goal-specific calorie and macro profiles, with manual targets validated within **±50 kcal**.
- Combined **50,000-feature TF-IDF cosine similarity**, **100-factor SVD collaborative filtering**, Bayesian weighted ratings, and nutrition-distance scoring to rank recommendations.
- Built a Streamlit meal planner with remaining-macro tracking, undoable meal selections, persistent ratings, and blocked-recipe preferences through SQLAlchemy and SQLite.

[Explore the repository →](https://github.com/Tanmay0448/nutricore-hybrid-diet-recommender) · [Try the live app →](https://nutricore-hybrid-diet-recommender.streamlit.app/)

### 👁️ [TransVision AI — Retinal Disease Detection](https://github.com/Tanmay0448/transvision-ai-retinal-disease-detection)

*Python · PyTorch · Flask · Vision Transformers*

TransVision AI is a retinal-image classifier covering ten eye-disease classes, paired with an accessible browser-based inference flow.

- Fine-tuned the **303M-parameter RETFound-MAE (ViT-L)** model for **100 epochs** on **16,242** augmented retinal images.
- Evaluated on **2,446** held-out images and achieved **92.19% accuracy**, **93.30% macro F1**, and **99.78% macro ROC-AUC**.
- Compared RETFound-MAE against EfficientNet-B7 and ViT-Base, selecting the final model through macro F1, ROC-AUC, and Cohen's kappa.
- Built a reusable PyTorch evaluation module that exports metrics, classification reports, and confusion matrices.
- Deployed the selected model with a Flask image-upload flow for JPG, JPEG, and PNG inputs up to 5 MB, returning the predicted class, confidence, and class-probability vector.

[Explore the repository →](https://github.com/Tanmay0448/transvision-ai-retinal-disease-detection)
